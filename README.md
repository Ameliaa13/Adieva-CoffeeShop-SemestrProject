# Adieva-CoffeeShop-SemestrProject


### Тема семестровки: Кофейня с мероприятями 

Кофейня — учебное веб-приложение на Java для кофейни, объединяющее онлайн-меню, оформление заказов и афишу мероприятий. Помимо обычных событий, приложение предлагает закрытые мероприятия: зарегистрированные пользователи получают доступ к ним после решения тематической загадки, создаваемой языковой моделью.

## Возможности

- Регистрация и вход пользователей, редактирование личных данных в профиле.
- Просмотр меню, категорий, описаний и пищевой ценности товаров.
- Добавление товаров в избранное и корзину, изменение количества и оформление заказа.
- Просмотр истории заказов в профиле.
- Просмотр афиши, регистрация на мероприятия и отмена регистрации с учётом доступных мест.
- Доступ к секретным мероприятиям после решения загадки.
- Генерация загадок через GigaChat с переходом на локальную Ollama-модель, если основной генератор недоступен.
- Административное управление товарами, категориями, мероприятиями и акциями.




## Технологический стек

## Архитектура

Приложение организовано по модели MVC. Сервлеты принимают запросы и выбирают представление, JSP отображают страницы, сервисный слой содержит прикладную логику, а репозитории работают с PostgreSQL через JDBC.

Код разделён по пакетам:

| Пакет | Назначение |
|---|---|
| `servlets` | Обработка HTTP-запросов и маршрутизация страниц и действий |
| `filter` | Проверка доступа и защита запросов |
| `listener` | Инициализация сервисов при запуске приложения |
| `service` | Интерфейсы и бизнес-логика |
| `repository` | Интерфейсы и JDBC-реализации доступа к данным |
| `model`, `mapper`, `enums` | Модели данных, преобразование результатов JDBC и перечисления |
| `ai` | Интерфейс и реализации генераторов загадок |
| `config`, `utils` | Конфигурация подключения и общие вспомогательные классы |
| `src/main/webapp/jsp` | JSP-страницы и общие фрагменты интерфейса |
| `src/main/webapp/css`, `src/main/webapp/img` | Стили и изображения |
| `src/main/resources` | SQL-схема и демонстрационные данные |

## Основные сущности и связи

Схема базы данных описана в `src/main/resources/schema.sql`. Она включает пользователей, категории, товары меню, акции, мероприятия, регистрации и решения загадок, корзины, заказы и позиции заказа.

- Связь многие-ко-многим между пользователями и товарами реализована через `favorites` и `cart_items`.
- Связь многие-ко-многим между пользователями и мероприятиями реализована через `event_registrations`.
- Связь один-ко-многим используется, например, между категориями и товарами, пользователями и заказами, заказами и позициями заказа.

## Требования для запуска

- JDK 21
- Maven
- PostgreSQL
- Apache Tomcat 11
- Ollama с установленной моделью (по умолчанию `gemma3:12b`), если нужна локальная генерация загадок
- Учётные данные GigaChat API, если нужно использовать основной онлайн-генератор

## Настройка

### 1. Создание базы данных

Создайте базу PostgreSQL и задайте переменные окружения для подключения:

| Переменная | Назначение | Пример |
|---|---|---|
| `DB_URL` | JDBC URL базы данных | `jdbc:postgresql://localhost:5432/coffeeshop` |
| `DB_USER` | Пользователь PostgreSQL | `postgres` |
| `DB_PASSWORD` | Пароль пользователя PostgreSQL | задаётся локально |

Сначала выполните `src/main/resources/schema.sql`. При необходимости загрузите демонстрационные данные из `src/main/resources/data.sql`. Перед повторным запуском `data.sql` проверьте его SQL-команды: скрипт очищает некоторые таблицы.

### 2. Настройка генерации загадок

Для GigaChat задайте `GIGACHAT_AUTH_KEY`. При необходимости также можно задать `GIGACHAT_SCOPE`, `GIGACHAT_MODEL` и `GIGACHAT_API_BASE_URL`.

Для локальной модели Ollama используются необязательные переменные `OLLAMA_BASE_URL` и `OLLAMA_MODEL`. По умолчанию приложение обращается к `http://localhost:11434` и модели `gemma3:12b`.

Не добавляйте ключи API и пароли в исходный код или README. Задавайте их в локальном окружении.

### 3. Сборка и запуск

Из корневой папки проекта выполните:

```bash
mvn clean package
```

Разверните полученный WAR-файл из папки `target` в Tomcat 11 и запустите сервер. Откройте приложение по адресу, который соответствует настройке контекста Tomcat, например `http://localhost:8080/CoffeeShop/`.

## Примечания

- Для просмотра меню и публичной афиши регистрация не требуется; личные функции доступны после входа.
- Секретные мероприятия предназначены для зарегистрированных пользователей и открываются после успешного решения загадки.
- Для демонстрации функций генерации загадок необходим доступ к GigaChat API либо запущенный локальный Ollama.
